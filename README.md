# Llama index学习
## demo01
基于Llama index框架，结合ollama实现100%本地离线私有文档问答，了解Llama index基本的实现过程
## demo02
向量索引持久化，防止耗时过长
- 生成对应的storage/文件夹，多次读取文件会直接从磁盘中加载到内存进行读取
- 当对应文档有进行改动的时候，要注意将对应的storage文件进行删除
## demo03
- 基础的文本切片-句子分割器
  调整对应参数可以提高向量相似度
  参数设定后对应句子的长度是固定的
- 向量相似度基础
  设定参数决定将前k个向量提供给大模型（没有设置的话默认是两个）
- 设定对应阈值，进行向量相似度基础筛选之后再进行阈值筛选
